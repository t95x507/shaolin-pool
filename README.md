# Убойный бильярд

Трешовый 3D-бильярд на three.js: у шаров есть здоровье, борта ломаются, взрывы прожигают сукно, а в запасе огненный шар, шаровая молния, чугунное ядро, чёрная дыра и Удар Дракона.

Всё в одном файле `index.html`, сборка не нужна.

## Режимы

- **Против Гены** — одиночная игра с ботом.
- **Создать комнату** — игра с другом по сети. Создатель получает ссылку вида `…/#K7QX2` и отправляет её другу. Друг открывает ссылку и жмёт «Подключиться».

## Как устроен мультиплеер

Соединение напрямую между браузерами через WebRTC (библиотека [PeerJS](https://peerjs.com/)). Для знакомства браузеров используется бесплатный публичный сервер PeerJS, сам сервер не нужен.

Создатель комнаты — «хост»: у него считается вся физика и правила, он играет красными, а кто разбивает пирамиду, решает жребий. Второй игрок получает состояние стола ~30 раз в секунду и отправляет хосту только прицел и удар. Поэтому вкладку хоста нельзя сворачивать во время партии: браузер останавливает фоновые вкладки, и игра встанет.

Если соединиться не получается, обычно мешает строгий NAT, корпоративная сеть или VPN. Помогает поменяться ролями или зайти с другой сети (например, с мобильного интернета).
